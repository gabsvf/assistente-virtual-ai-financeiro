# Entrega do projeto

## Nome

**FinAssist IA - Assistente Virtual Financeiro Educacional**

## Problema

Usuários precisam de respostas rápidas para dúvidas financeiras simples, mas uma resposta automatizada precisa considerar contexto, dados confiáveis e segurança.

## Solução

O FinAssist IA combina uma interface de chat, uma base pequena de conhecimento, perfis fictícios, simulações financeiras e uma camada de segurança. A IA generativa pode ser conectada de forma opcional, enquanto o fallback permite demonstrar a solução sem depender de serviços externos.

## Diferenciais demonstráveis

- GenAI + recuperação de conhecimento.
- Simulações financeiras explicáveis.
- Proteção básica contra dados sensíveis.
- Proteção contra prompt injection explícito.
- Arquitetura simples para estudo e apresentação.
- Projeto reproduzível em computador local.

## Roteiro de apresentação

1. Apresentar o problema.
2. Mostrar a interface e o perfil fictício.
3. Perguntar sobre CDI e reserva de emergência.
4. Rodar o simulador de investimento.
5. Testar o bloqueio de prompt injection.
6. Mostrar como a API de IA é opcional e como o fallback mantém o produto funcionando.
7. Destacar as medidas de segurança e os limites do protótipo.
